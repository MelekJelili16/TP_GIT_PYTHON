# TP : Publier et synchroniser un projet Python (TP_GIT_PYTHON)
## Présentation
Ce projet s'inscrit dans le cadre de l'apprentissage des outils collaboratifs (Git et GitHub). Il s'appuie sur le développement d'un programme Python interactif nommé **"Mon assistant de révision"** (`main.py`), conçu pour guider l'utilisateur dans l'organisation de ses sessions d'étude.

## Évolution du programme (Versions V1 à V4)
Le projet a évolué à travers quatre versions successives :
- **V1 :** Création initiale du programme en local avec un message de bienvenue de base.
- **V2 :** Ajout de la saisie du prénom de l'utilisateur et premier envoi (*push*) vers le dépôt distant GitHub.
- **V3 :** Modification directement en ligne sur GitHub pour ajouter la saisie de la matière à réviser, puis récupération (*pull*) sur le PC.
- **V4 :** Ajout local de la durée de révision en minutes et nouveau commit suivi d'un dernier *push* vers GitHub.

##  Utilisation et Exécution
### Prérequis
- Python installé sur votre machine.
- Visual Studio Code (VS Code).

### Lancer le programme
1. Ouvrez le dossier `TP_GIT_PYTHON` dans VS Code.
2. Ouvrez le fichier `main.py`.
3. Cliquez sur le bouton de lecture **(Run Python File)** en haut à droite de l'éditeur, ou tapez dans le terminal :
   ```bash
   python main.py
